## 一、这个库是什么

| 项 | 内容 |
|---|---|
| 数据来源 | 30 个品牌站点/官网产品页，`电动工具爬虫/` 下的 `crawler_*.py` |
| 型号总数 | **8790 条**（含东成 B2B 商城型号 639 条、安海 733 条） |
| 组织维度 | **21 家公司**：东成集团（单列，不占国内名额）+ 国内 10 家 + 国外 10 家（含安海 Einhell，733 条） |
| 子品牌归并 | 泉峰 = 大有 + 福莱克斯 + EGO + SKIL；TTI = 美沃奇 + RYOBI + AEG；SBD = 史丹利 + 得伟；东成集团 = 东成 / DCA / DCK / dongcheng |

## 二·补 数据落盘规范（2026-11-12 起）

以后新爬或重爬品牌，数据只填这两个目录，不再用旧的 `output/` 与 `图片库/`：

| 内容 | 落到 | 命名 / 说明 |
|---|---|---|
| 产品 JSON、分类、总表、URL 缓存、日志 | `型号数据/` | `<品牌>_产品数据.json`、`品牌分类.json`、`_XXX_urls.json` |
| 产品原图 | `图片数据/images/<品牌>/` | URL 的 md5 前 12 位 + 扩展名，自动去重 |
| 品牌 logo | `图片数据/brands/` | `logo.<品牌>.<ext>` |

- `common.py` 的 `OUTPUT_DIR` / `IMAGE_BASE_DIR` 已指向这两个目录；新爬虫直接 `from common import OUTPUT_DIR, IMAGE_BASE_DIR` 即可。
- 爬虫跑完执行 `python fetch_missing_images.py` 补齐只有官网直链的图片，并把 `local_image` 回填成相对本库根目录的路径（如 `图片数据/images/安海/xxx.jpg`）；失败明细写 `型号数据/_图片下载失败.json`。
- 需要查询页显示图片时再跑 `python build_thumbs.py` 重建缩略图索引。
- 2026-11-12 已把历史 JSON 里 4022 条失效的绝对路径 `local_image` 修成有效相对路径。

## 六、用之前必须知道的坑

1. **格力博数据口径彻底换了**：现在是美国官方商城（greenworkstools.com）的 76 个在售/清仓 SKU，字段和界面语言都是英文；`category1` 取集合名，`model` 取 Shopify SKU，价格有 62 条真实值。旧 360 条俄文数据（`G40HT61 Комплект: Кусторез` 那批，电压写 `Нет`）已整体删除，不要再引用。
2. **新五家的字段口径与旧品牌有差异**：
   - 牧田：`power_w` 优先「额定输入功率」，没有则取「最大输出功率」；冲击类工具的「冲击数(ipm)/冲程速度(spm)/轨道转数(opm)」都归入 `冲击频率`
   - 泛音：规格值为英制[公制]双标原文（如 `3.09 [1.40] lbs[kg]`）；同型号不同套装用型号+SKU 尾号区分
   - 福莱克斯：24V 平台统一标 24V，规格表只给功能开关（Yes/No），功率无值；`model` 为 FX 编码
   - 费斯托：`model` 为 art number（如 578367），规格键为英文原文（`Battery voltage (rated voltage)` 等）；63 条 charge/AC 类型未知
   - 格力博：`voltage` 来自 tags/规格里的 24V/40V/60V/80V/82V 识别
3. **费斯托爬虫依赖一次性 token**：`_festool_token.json` 里缓存了匿名 JWT（约 1 小时有效），过期后脚本会自动用 Playwright 重新取；`/api/products/grid` 不带 `authorization: Bearer` 一律 401。
4. **格力博/牧田/费斯托都靠"真浏览器态"**：格力博必须 headless=False 过 Cloudflare（headless 直接挑战页）；牧田图片不带 PHPSESSID 会全返回同一张 logo；费斯托详情走 SSR 无盾但图片 CDN 慢（curl 5-6 秒/张）。
5. **数据是 2026 年 11 月的快照**，官网下架、改型号、改参数都不会自动同步；参数填充率低主要是官网页面本身没写，不是漏爬，判关键参数前最好回官网链接核对。
6. **318 条的「产品型号」列原本是商品 ID**（形如 `东成-1641179325156`），导出时已挪到 `商品ID` 字段并从名称里回解真实型号，但源表里还是错的。
7. **按公司维度组织，别再数品牌数**：东成集团单列（旗下东成 / DCA / DCK / dongcheng 4 个子品牌，不占国内名额）；国内 10 家公司、国外 10 家公司（含安海 Einhell，733 条）；史丹利 + 得伟 = SBD 1 家，泉峰 4 个子品牌、TTI 3 个子品牌。合计 21 家公司 / 30 个品牌文件 / 8790 条；总表是「汇总 + 21 个公司 sheet」。
8. **TTI 归国外**：创科实业依香港法律注册、总部香港（港股 00669），是港资跨国集团，既非大陆本土品牌也不是美国公司；按本库口径（国内 = 大陆本土，国外 = 外资/国际品牌）归【国外】。旗下已采美沃奇 / RYOBI / AEG 三个子品牌，共 1 家公司。
9. **新补采 4 个子品牌的数据口径与手持工具有差异**：EGO 是 OPE（割草机/吹风机/清洗机等），规格只在 JSON-LD 描述文本里（56V / CFM / MPH / 续航），无额定功率；SKIL 是 Shopify，规格在 `description` 非结构化、结构化 `specs` 几乎为空，但有真实 USD 价格；RYOBI sitemap 含 2834 个套装变体，只取前 500 主产品；AEG 规格键为英文原文（`No load speed (rpm)` 等），一个页面常含多个型号变体。四者图片此前未入本地，2026-11-12 起由 `fetch_missing_images.py` 补入 `图片数据/`。
10. **安海数据口径**：产品目录在 `einhell.co.uk`（集团站 `einhell.com` 只有品牌页）；货号取自 `/p/<货号>-<slug>/`，规格键为英文原文、来自 `id="technical-details"` 的 div 键值表；`型号数据/_EINHELL_urls.json` 缓存 736 个产品 URL，重跑可复用；图片为 cloudfront CDN 直链，补采见 `fetch_missing_images.py`。
