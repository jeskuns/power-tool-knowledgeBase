怎么用

三种打开方式

  • 公司内网 / 本机：直接双击本页，或跑 python -m http.server 8080 后打开 knowledge/index.html。
  • 手机：把整个 知识库 文件夹拷进手机，用浏览器打开本页；只想要一个库时，单个 HTML 文件（如 安规标准知识库.html）就能独立打开。
  • APK：打包 App 时把六个库一起同步进 webDir；不想要体积就先把 knowledge/电动工具测试标准与认证知识库/全文 排除。

内容从哪来，怎么更新

  • 这里是源文件目录（Documents\lifeOS\数字化\实验室管理\知识库\），六个库与主页在此维护；company\gongchengbu\knowledge\ 是同步到实验室管理的备份。
  • 更新源数据后：跑 python _脚本/build_query_kb_all.py 刷新六库单文件 md；实验室管理备份用 robocopy 从本目录增量同步。
  • 查询数据由 python knowledge/tools/build_kb_data.py 生成到 knowledge/query/data/；标准卡片由 电动工具测试标准与认证知识库/_脚本/kb_html.py 从 卡片/*.md 生成。
