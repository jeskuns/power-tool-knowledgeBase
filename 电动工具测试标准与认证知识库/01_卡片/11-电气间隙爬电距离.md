# 11 — 电气间隙与爬电距离（Clearances & Creepage Distances）

## 0 · 速查结论

| 项目 | 电动工具（60745/62841/GB 3883.1） | 家用电器（60335/GB 4706） |
|------|--------------------------------------|---------------------------|
| 条款号 | 60745 §28 / 62841 §28 | §29 |
| 表格 | 60745 Table 10 / 62841 Table 12 | 引用 IEC 61558-1 Table 13 |
| 电压分档 | ≤130 / ≤250(60745)或≤280(62841) / ≤440(60745)或≤480(62841) | 按过电压类别（I/II/III） |
| 基本绝缘（≤250V） | 爬电 1.5–2.0 mm / 间隙 1.0–1.5 mm | 按 Table 13 |
| 加强绝缘（≤250V） | 爬电 3.0–4.0 mm / 间隙 2.0–3.0 mm | 按 Table 13 |

| 测量力 | 裸导线 2 N / 外壳 30 N | 裸导线 2 N / 可触及表面 30 N |
| PCB 特殊规定 | 有（防污 0.2 mm / 不防污 0.5 mm） | 有（Annex J 涂层） |

## 1 · 试验条件与方法

### 1.1 适用范围

**依据**：IEC 60745-1 §28.1 / IEC 62841-1 §28.1 / IEC 60335-1 §29

- 爬电距离和电气间隙不得小于标准规定值
- **不适用于**：电机绕组交叉点
- 如存在谐振电压（绕组与电容连接点与仅被基本绝缘隔开的金属件之间），需按谐振电压值增加距离，加强绝缘额外 +4 mm

### 1.2 测量条件

| 条件 | 要求 |
|------|------|
| 插头插座 | 插入合适的连接器后测量 |
| X 型接线 | 用最大截面导线 + 无导线两种状态 |
| 皮带传动 | 皮带在位（最不利张力）+ 皮带拆下，两种状态 |
| 可动部件 | 置于最不利位置 |
| 非圆形螺母/螺钉 | 假设拧至最不利位置 |
| 端子到可触及金属 | 螺钉/螺母松开至最大程度测量，间隙不得小于表列值的 **50%** |
| 绝缘外壳开孔 | 用金属箔贴可触及表面，用标准试验指推入角落（不压入开孔） |

### 1.3 测量力

| 施加对象 | 力值 |
|----------|------|
| 内部接线和裸导线 | **2 N** |
| 恒温器/类似装置的未绝缘金属毛细管 | **2 N** |
| 金属外壳外部 | **30 N** |
| 施力工具 | IEC 61032 试验探棒 B |

### 1.4 基本绝缘与功能绝缘（PCB 特殊规定）

**依据**：IEC 62841-1 §28.1

导电印制线路板（不含边缘）的不同电位部分之间，距离可减小至：

| 防护条件 | 最大电压应力 | 最小距离 |
|----------|-------------|---------|
| 防污（有涂覆保护） | 150 V/mm | **0.2 mm** |
| 不防污 | 100 V/mm | **0.5 mm** |

如上述计算值大于表列值，取表列值。

**依据**：§29.1，引用 IEC 61558-1 Table 13

- 按 **过电压类别**（I / II / III）和 **额定冲击电压**（1500 / 2500 / 4000 / 6000 / 8000 / 10000 V）查表

## 3 · 标准间差异

| 差异点 | 60745-1 §28 | 62841-1 §28 | 60335-1 §29 |
|--------|-------------|-------------|-------------|
| 表格编号 | Table 10 | Table 12 | 引用 IEC 61558-1 Table 13 |
| 电压分档 | ≤130 / ≤250 / ≤440 V | ≤130 / ≤280 / ≤480 V | 按额定冲击电压 |
| 过电压类别 | 未采用 | 明确采用 OVC II | 明确采用 OVC II |
| PCB 特殊规定 | 无 | 有（§28.1，防污 0.2 mm / 不防污 0.5 mm） | 有（Annex J 涂层） |
| 光耦内部 | 无规定 | 不测量（如密封良好且排除空气） | 无规定 |
| 不同极性带电体 | 无规定 | 可减小（需满足 §18 短路试验） | 无规定 |
| 测量力 | 未明确 | 2 N / 30 N（IEC 61032 探棒 B） | 2 N / 30 N（IEC 61032 探棒 B） |

**62841-1 vs 60745-1 关键变化**：
- 电压分档上限从 440 V 提高到 480 V（适应更高工作电压）
- 引入 IEC 60664-1 过电压类别体系
- 新增 PCB 导电线路的特殊距离规定
- 新增光耦内部绝缘不测量的规定
- 新增不同极性带电体可减小距离的规定（需通过 §18 异常操作试验验证）
- 明确测量力的施力工具为 IEC 61032 探棒 B

---

## 4 · 常见坑点

1. **电压分档不同**：60745 用 250/440 V，62841 用 280/480 V，查表时注意对应
2. **加强绝缘到可触及金属的距离远大于基本绝缘**：5–8 mm vs 2–3 mm
3. **螺钉松开后间隙不得小于表列值 50%**：这是最低要求，不是合格线
4. **PCB 距离可以小于表列值**：但有电压应力密度限制（150 或 100 V/mm）
5. **谐振电压情况需额外增加 4 mm（加强绝缘）**：容易遗漏
6. **62841 允许不同极性带电体减小距离**：前提是短路后仍通过 §18 试验
7. **测量时施加力**：裸导线 2 N，外壳 30 N，用力过大会导致实测值偏小
8. **绝缘外壳开孔测量**：金属箔要贴入角落但不压入开孔，方法容易做错
9. **海拔 >2000 m 需修正**：空气稀薄，电气间隙需乘以增大系数
10. **漆包绕组/防污处理可降低要求**：但"防污"定义要严格，不是随便涂一层就行
