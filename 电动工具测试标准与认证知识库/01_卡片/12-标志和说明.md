# 12 — 标志和说明（Marking & Instructions）

## 0 · 速查结论

| 项目 | 电动工具（60745/62841） | 家用电器（60335） |
|------|--------------------------|-------------------|
| 条款号 | §8 | §7 |
| 标志内容 | 电压/电流/功率/厂商/型号/类别/IP/警告 | 电压/电流/功率/厂商/型号/类别/IP |

| 标志位置 | 主壳体 | 主壳体 |

## 1 · 标志要求

### 1.1 必备标志

**依据**：IEC 60745-1 §8.1 / IEC 62841-1 §8.1 / IEC 60335-1 §7.1

| 标志项 | 工具 | 家电 |
|--------|------|------|
| 额定电压（V）或电压范围 | ✓ | ✓ |
| 电源性质符号（~） | ✓（除非标频率） | ✓（除非标频率） |
| 额定输入功率（W）或额定电流（A） | ✓ | ✓ |
| 制造商名称/商标/地址 | ✓ | ✓ |
| 型号标识 | ✓ | ✓ |
| Ⅱ类结构符号（回字） | ✓（仅Ⅱ类） | ✓（仅Ⅱ类） |
| IP 防护等级（非 IPX0 时） | ✓ | ✓ |
| 安全警告语 | ✓ | — |

### 1.2 警告语要求（仅工具）

**依据**：IEC 60745-1 §8.1 / IEC 62841-1 §8.2

三种形式可选：
1. 文字："WARNING – To reduce the risk of injury, user must read instruction manual"
2. 符号：ISO 7010 M002
3. 第二部分规定的专用符号

**文字要求**：
- "WARNING" 必须大写字母，高度 ≥ **2.4 mm**
- 警告语不得与 "WARNING" 分离
- 可用 "operator's manual" 或 "user guide" 替代 "instruction manual"

### 1.3 短时/间歇工作制标志

**依据**：IEC 60745-1 §8.2 / IEC 60335-1 §7.2

- 短时工作制：标额定运行时间
- 间歇工作制：标额定运行时间 / 额定休息时间
- 如结构本身限制了运行时间，可不标

### 1.4 多电压标志

**依据**：IEC 60745-1 §8.3–8.5 / IEC 62841-1 §8.1.1–8.1.2

| 情况 | 标志方式 | 示例 |
|------|---------|------|
| 无需调节的电压范围 | 上下限用"-"连接 | 115-230 V |
| 需调节的不同电压 | 各值用"/"分隔 | 115/230 V |
| 星-三角连接 | 标两种电压 | 230∆/400Y |
| 多电压对应不同功率 | 各电压对应功率均需标 | — |

## 2 · 说明书要求

### 2.1 通用要求

**依据**：IEC 60745-1 §8.14 / IEC 62841-1 §8.14 / IEC 60335-1 §7.12

- 必须提供使用说明书
- 说明书语言：使用地官方语言
- 电池工具：必须包含充电相关说明

### 2.2 工具专用说明内容

**依据**：IEC 60745-1 §8.14 / IEC 62841-1 §8.14

说明书必须包含：
- 安全警告
- 附件使用说明
- 维护保养说明
- 电池充电说明（如适用）
- 振动排放值（62841-1 新增）

### 2.3 家电专用说明内容

**依据**：IEC 60335-1 §7.12

- 安装注意事项（如适用）
- 固定接线器具的接线方法
- 连接水管器具的水压要求
- 嵌入式器具的安装说明

---

## 3 · 标志耐久性

### 3.1 试验方法

**依据**：IEC 60745-1 §8.15 / IEC 62841-1 §8.15 / IEC 60335-1 §7.14

- 标志必须清晰耐久
- 耐擦拭试验：用水擦拭 15 s，再用脂肪烃（正己烷）擦拭 15 s
- 试验后标志仍应清晰可辨，不卷边

### 3.2 标志位置

**依据**：IEC 60745-1 §8.16 / IEC 62841-1 §8.16 / IEC 60335-1 §7.15

- 标志应在主壳体上
- 电池标志可在电池上
- 铭牌不应位于可拆卸盖板上（除非盖板拆卸不影响标志）

## 4 · 标准间差异

| 差异点 | 60745-1 §8 | 62841-1 §8 | 60335-1 §7 |
|--------|-----------|-----------|-----------|
| 警告语 | 强制（文字或 M002） | 强制（文字或 M002） | 无 |
| 振动值 | 无 | 必须标注 | 无 |
| 电池说明 | 有 | 有（更详细） | 有 |
| 耐久性试验 | 水+正己烷擦拭 | 水+正己烷擦拭 | 水+正己烷擦拭 |
| 符号标准 | IEC 60417 | IEC 60417 | IEC 60417 |

**62841-1 vs 60745-1 关键变化**：
- 新增振动排放值标注要求
- 电池工具说明要求更详细
- 警告语符号引用更新为 ISO 7010

---

## 5 · 常见坑点

1. **警告语高度≥2.4mm**：低于此高度不合格
2. **"WARNING"必须大写**：小写不合格
3. **多电压必须标对应功率**：只标电压不标功率不合格
4. **星-三角连接必须标两种电压**：只标一种不合格
5. **说明书必须包含安全警告**：缺项不合格
6. **标志耐久性试验顺序**：先水后溶剂，不能颠倒
7. **62841-1 必须标振动值**：60745-1 无此要求
8. **电池标志可在电池上**：但其他标志必须在主壳体
