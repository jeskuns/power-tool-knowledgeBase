# 16 — 防潮和湿热（Moisture Resistance & Humidity）

## 1 · IP 防护等级试验

### 1.1 试验依据

**依据**：IEC 60745-1 §14.1 / IEC 62841-1 §14.2 / IEC 60335-1 §15.1

- 外壳必须提供与器具分类相应的防湿气保护等级
- 按 IEC 60529 进行相应 IP 等级试验

### 1.2 IP 等级对应试验

| IP 等级 | 试验方法 |
|---------|---------|
| IPX1 | 滴水试验（垂直滴水） |
| IPX2 | 倾斜 15° 滴水试验 |
| IPX3 | 淋水试验（摆管 60°） |
| IPX4 | 溅水试验（摆管 180°） |
| IPX5 | 喷水试验（喷嘴 6.3mm） |
| IPX6 | 强烈喷水试验（喷嘴 12.5mm） |
| IPX7 | 浸水试验（1% NaCl 溶液） |

### 1.3 试验条件

**依据**：IEC 60745-1 §14.1.1 / IEC 62841-1 §14.2.1 / IEC 60335-1 §15.1.2

- 器具**不接电源**
- 手持器具在试验中**连续转动**至最不利位置
- 可拆卸部件（无需工具即可拆除的）拆除后一同试验
- X 型接线器具配最轻最细的允许软线

### 1.4 判定

- 试验后立即通过**耐压试验**（§15 / §16.3 / Annex D）
- 绝缘上**不得有水迹**可能导致电气间隙/爬电距离降低

---

## 2 · 溢出试验

### 2.1 适用范围

**依据**：IEC 60745-1 §14.2 / IEC 60335-1 §15.2

- 正常使用中可能溢出液体的器具

### 2.2 试验方法

| 项目 | 工具（60745） | 家电（60335） |
|------|---------------|---------------|
| 溶液 | 1% NaCl 水溶液 | 1% NaCl + 商用洗涤剂 |
| 填充 | 容器完全充满 | 容器完全充满 |
| 追加量 | 15% 容量或 0.25L（取大者） | 15% 容量或 0.25L（取大者） |
| 倒入时间 | 1 分钟内匀速倒入 | 1 分钟内匀速倒入 |

### 2.3 判定

- 试验后立即通过耐压试验
- 绝缘上不得有水迹导致电气间隙/爬电距离降低
- 器具放置 24h（正常大气条件）后进行湿热试验

---

## 3 · 湿热试验

### 3.1 试验条件

**依据**：IEC 60745-1 §14.3 / IEC 62841-1 §14.1 / IEC 60335-1 §15.3

| 参数 | 条件 |
|------|------|
| 相对湿度 | **(93 ± 3)%** |
| 温度 | 20-30°C 之间任一值 t（±2K） |
| 时间 | **48 h** |
| 样品预处理 | 在 t 到 t+4°C 下放置至少 4h |
| 溶液制备 | Na₂SO₄ 或 KNO₃ 饱和水溶液（大接触面积） |

### 3.2 试验准备

- 电缆入口保持敞开
- 如有敲落孔，打开一个
- 可拆卸部件拆除后一同试验

### 3.3 试验后判定

**依据**：IEC 60745-1 §14.3 / IEC 62841-1 §14.1 / IEC 60335-1 §15.3

- 在湿热箱内或恢复至预处理温度的房间内
- 重新组装可拆卸部件后
- 通过**耐压试验**：
  - 工具：Clause 15（60745）/ Annex D（62841）
  - 家电：Clause 16.3

### 3.4 62841-1 附加要求

**依据**：IEC 62841-1 §14.1

- 在软线入口/软线固定装置/软线夹紧处
- 软线用金属箔包裹
- 夹紧螺钉按 Table 11 扭矩拧紧
- 在易触及金属件与软线之间施加耐压：
  - Ⅰ类工具：**1250 V**
  - Ⅱ类工具：**1750 V**

## 4 · 标准间差异

| 差异点 | 60745-1 §14 | 62841-1 §14 | 60335-1 §15 |
|--------|-----------|-----------|-----------|
| 条款号 | 14 | 14 | 15 |
| IP 试验 | IEC 60529 | IEC 605229 | IEC 60529 |
| 溢出溶液 | 1% NaCl | 1% NaCl | 1% NaCl + 洗涤剂 |
| 湿热条件 | 48h / 93%RH / 20-30°C | 48h / 93%RH / 20-30°C | 48h / 93%RH / 20-30°C |
| 试验后耐压 | §15 | Annex D（湿热箱内） | §16.3 |
| 附加耐压 | 无 | 有（软线入口 1250/1750V） | 无 |
| 转动速率 | 未明确 | ~1 rev/min | 未明确 |

**62841-1 vs 60745-1 关键变化**：
- 新增软线入口附加耐压试验（金属箔包裹软线）
- 明确转动速率约 1 rev/min
- 耐压试验在湿热箱内进行（不是取出后）

**家电 vs 工具差异**：
- 溢出试验溶液含洗涤剂（工具不含）
- 条款号不同（§15 vs §14）

## 5 · 常见坑点

1. **IPX7 用 1% NaCl 溶液**：不是清水，是盐水
2. **溢出量取大者**：15% 容量或 0.25L，不是固定值
3. **溢出倒入时间 1 min**：必须匀速，不能一次倒入
4. **湿热试验 48h**：不是 24h 或 72h
5. **湿度 93%±3%**：必须严格控制
6. **温度 20-30°C 之间**：具体值 t 可选，但全程 ±2K
7. **预处理至少 4h**：样品必须先在 t 到 t+4°C 下放置
8. **溶液制备**：用 Na₂SO₄ 或 KNO₃ 饱和溶液，不是随便配
9. **62841-1 附加耐压**：软线入口用金属箔包裹后测，容易遗漏
10. **试验后耐压在湿热箱内做**：不是取出后做（62841-1）
