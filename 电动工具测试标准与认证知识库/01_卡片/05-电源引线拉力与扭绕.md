## 2 试验条件表

### 2.1 拉力试验

| 项目 | 要求 |
|------|------|
| 试验次数 | **25次** |
| 拉力方向 | **最不利方向**（most unfavorable direction） |
| 施力方式 | **无冲击**（without jerking） |
| 每次持续时间 | **1 s** |
| 标记位置 | 软线固定装置或参考点外约 **20 mm** 处做标记 |
| 测量时机 | 拉力施加状态下测量标记位移 |

### 2.2 扭矩试验

| 项目 | 要求 |
|------|------|
| 试验时机 | 拉力试验**完成后立即**进行 |
| 施加位置 | **尽可能靠近**软线固定装置 |
| 持续时间 | **1 min** |
| 适用范围 | 自动卷线器以外的所有软线 |

### 2.3 软线固定装置结构要求

| 标准 | 条款 | 要求 |
|------|------|------|
| 60745-1 | 24.14 | 软线固定装置应使导体在连接处免受拉力和扭绕应力 |
| 60745-1 | 24.14 | 绝缘层应防磨损 |
| 60745-1 | 24.14 | 不得将软线推入工具内部至损坏软线或内部零件的程度 |
| 60745-1 | 24.15 | 软线固定装置应只能用工具触及，或只能用工具安装软线 |
| 60745-1 | 24.16 | X型联接的软线固定装置：更换软线应容易；防拉防扭方式应清晰；不同软线类型均有效（除非专用软线） |
| 60745-1 | 24.16 | 软线不得接触夹紧螺钉（除非螺钉与易触及金属之间有附加绝缘） |
| 60745-1 | 24.16 | 软线不得由直接压在软线上的金属螺钉固定 |
| 60745-1 | 24.16 | 至少一部分固定装置应牢固固定在工具上（除非是专用软线的一部分） |
| 62841-1 | 24.14 | 同上，但增加：压盖（glands）不得用作软线固定装置 |
| 60335-1 | 25.16 | 同上，但增加：对于Ⅰ类工具，如果软线绝缘故障可能使易触及金属带电，固定装置应为绝缘材料或有绝缘衬里 |
| 60335-1 | 25.16 | 对于Ⅱ类工具，固定装置应为绝缘材料或与易触及金属之间有附加绝缘（软线护套单独不满足此要求） |

### 2.4 软线弯曲试验（24.11 / 25.14）

| 项目 | 要求 |
|------|------|
| 适用范围 | 使用中会弯曲的软线（自动卷线器除外） |
| 试验设备 | 类似图2的摆动装置 |
| 摆动角度 | 90°（垂直两侧各45°） |
| 弯曲次数 | **20,000次** |
| 弯曲速率 | **60次/min** |
| 负载质量 | 工具质量（按5.17），但不小于2 kg，不大于6 kg |
| 10,000次后 | 试样绕软线中心线旋转90°，继续弯曲 |
| 试验后要求 | 导体断裂数不超过10% |

### 2.5 软线护套弯曲试验（24.12 / 25.13）

| 项目 | 要求 |
|------|------|
| 适用范围 | 带软线护套的工具 |
| 软线长度 | 软线护套出口外约 **100 mm** |
| 放置角度 | 软线护套轴线与水平面成 **45°**（软线无应力状态） |
| 负载质量 | **10 D² g**（D为软线外径，mm） |
| 温度要求 | 如果护套对温度敏感，试验在 **(23±2)°C** 进行 |
| 试验后要求 | 软线曲率半径不得小于 **1.5 D** |

## 3 体系差异要点

1. **条款编号差异**：
   - 60745-1/GB 3883.1：clause **24**.14（拉力扭矩）、24.15（固定装置可及性）、24.16（X型联接要求）
   - 62841-1：clause **24**.13（拉力扭矩）、24.14（固定装置可及性）、24.15（X型联接要求）
   - 60335-1/GB 4706.1：clause **25**.15（拉力扭矩）、25.16（固定装置可及性）、25.17（X型联接要求）

2. **表格编号差异**：
   - 60745-1/UL 60745-1：Table **7**
   - 62841-1：Table **9**
   - 60335-1：Table **12**

3. **压盖（glands）使用**：62841-1明确禁止压盖用作软线固定装置；60745-1和60335-1无此明确禁止。

4. **软线弯曲试验**：62841-1和60335-1有专门的软线弯曲试验（24.11 / 25.14）；60745-1无此独立条款（可能在第二部分中规定）。

5. **软线护套弯曲试验**：62841-1（24.12）和60335-1（25.13）均有；60745-1在24.13中有类似要求。

6. **UL 60745-1 偏差**：
   - 24.1DV：软线长度应小于0.5 m或大于1.8 m（特殊要求）
   - 24.4DV：软线固定装置的夹紧螺钉扭矩要求可能不同
   - 24.6DV：Ⅰ类工具软线颜色要求（绿/黄组合色）

7. **家电标准特殊要求**：
   - 60335-1 25.16：Ⅰ类和Ⅱ类工具的软线固定装置绝缘要求更详细
   - 60335-1 25.17：X型联接的软线固定装置要求与工具标准基本一致

8. **位移测量方法**：所有标准要求相同——在软线固定装置外约20 mm处做标记，拉力施加状态下测量标记位移。

## 4 注意点

1. **拉力方向**：必须在**最不利方向**施加拉力——实际测试时需要尝试多个方向，找到最大位移的方向。

2. **施力方式**：必须**无冲击**（without jerking）——快速施力会导致瞬时力过大，不符合标准要求。

3. **扭矩施加位置**：必须**尽可能靠近**软线固定装置——远离固定装置施力会导致测试结果不准确。

4. **试验顺序**：先做25次拉力试验，**立即**做扭矩试验——中间不得有其他操作。

5. **软线弯曲试验**：20,000次弯曲分两阶段，每阶段10,000次，第二阶段前试样旋转90°——这是为了模拟实际使用中软线的多方向弯曲。

6. **软线护套弯曲试验**：负载质量与软线外径的平方成正比（10 D² g）——粗软线需要更大的负载。

7. **位移测量**：标记位置距软线固定装置约20 mm——太近或太远都会影响测量结果。

8. **导体断裂判定**：软线弯曲试验后，导体断裂数不超过10%——需要逐根检查每根宗股线。

9. **压盖禁用**：62841-1明确禁止压盖用作软线固定装置——设计时注意避免使用电缆压盖（cable glands）。

10. **UL软线长度限制**：UL 60745-1要求软线长度<0.5 m或>1.8 m——出口美国产品需特别注意。
