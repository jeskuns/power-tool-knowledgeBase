# P06 手持式搅拌机

- 适用标准：IEC 62841-2-10 (2017)
- 配合使用：IEC 62841-1 通用要求
- 适用范围：手持式搅拌机（用于搅拌液体或建筑材料如混凝土、石膏等）
- 不适用范围：电钻和冲击钻（即使可用作搅拌机，归 IEC 62841-2-1）
- 注意：搅拌机不被视为带液体系统的工具

---

## 1 术语定义

| 编号 | 术语 | 定义要点 |
|------|------|----------|
| 3.101 | mixer 搅拌机 | 配备一个或多个输出主轴，安装搅拌篮，用于搅拌液体或混合建筑材料（混凝土、石膏等） |
| 3.102 | mixer basket 搅拌篮 | 用于搅拌机的附件，采用翼片、螺旋或螺旋结构在容器中移动材料 |

**注：**
- 输出主轴可以是螺纹或夹头/六角连接器
- 搅拌篮也称为搅拌棒、搅拌篮、桨叶或搅拌杆
- 搅拌机也称为搅拌器

## 2 标志与说明（§8 增补）

### 2.1 额外铭牌信息（§8.3）
- **螺纹主轴搅拌机**：标记主轴螺纹尺寸
- **六角连接器搅拌机**：标记对边宽度
- **带夹头搅拌机**：夹头标记最大容量（mm）

### 2.2 安全警告（§8.14.1.101）

**搅拌机安全说明：**
- 双手握持工具在预期手柄处——失控可致人身伤害
- 搅拌易燃材料时确保充分通风，避免危险气氛
- **不要搅拌食物**——电动工具及其附件不用于食品加工
- 保持软缆远离工作区——软缆可能被搅拌篮缠绕
- 确保搅拌容器放置在稳固安全的位置
- 防止液体溅到工具外壳上——渗入的液体会导致损坏和触电
- 遵循待搅拌材料的说明和警告
- 如工具掉入搅拌材料中，**立即拔掉电源插头**并由合格人员检查
- **不要用手或其他物体伸入搅拌容器**
- 仅在搅拌容器内启动和停止工具——搅拌篮可能弯曲或失控旋转

**注：** 制造商可自行决定将"mixer/mixed/mixing"替换为"stirrer/stirred/stirring"，将"basket"替换为其他适当术语如"rod"

### 2.3 说明书附加内容（§8.14.2）
- 可用搅拌篮信息（包括最大直径或宽度）
- 可用延伸杆信息

## 7 机械危险（§19 替换/新增）

| 条款 | 要求 | 符合性 |
|------|------|--------|
| §19.1 首段**替换** | 除**输出主轴和搅拌篮**外的运动及危险部件，须通过布置或封闭来防止人身伤害 | — |
| §19.4 **替换** | 搅拌机**至少两个手柄** | 目视检查 |
| §19.4.101 新增 | 手柄设计须使操作者**能控制作业时的扭矩** | 测量 + 计算，见 §7.1 |
| §19.6 | **不适用** | — |
| §19.101 新增 | 多主轴搅拌机主轴须**充分隔开**以降低缠绕风险：主轴出口处及**沿搅拌篮再向下 100 mm** 范围内，旋转件间最小间隙 **c ≥ 40 mm**（Figure 103） | 测量 |
| §19.102 新增 | **夹头钥匙**须设计成松手后**轻易脱出**；允许用卡夹存放松用钥匙，但**禁止固定在软缆/软线上的金属卡夹** | 目视检查 + 手动试验 |

### 7.1 §19.4.101 手柄力臂计算（Figure 102）

| 项 | 要求 |
|----|------|
| S | 操作者**自然握持处**在电源开关上的位置 |
| x | 距 S 沿握持方向 **80 mm**，或手柄剩余长度（取较小者）的测量点 |
| a | **力臂**（按 Figure 102 确定） |
| 判据 | **两个手柄力臂之和 ≥ §8.14.2 a) 101) 推荐的最大搅拌篮的直径或宽度** |
| 手柄多于两个 | 按 §8.14.2 b) 6) 的**最不利布置**取值，且其中一个手柄须包含电源开关 |

### 7.2 §19.102 夹头钥匙试验
钥匙插入夹头、**不拧紧**，把工具转到**钥匙朝下**——钥匙**应能自行落出**。

## 8 机械强度（§20 替换）

### 8.1 §20.3.1 替换——倾倒冲击试验

| 项 | 要求 |
|----|------|
| 冲击次数 | **3 次**（工具倾倒撞击**混凝土表面**） |
| 装配 | 装制造商按 §8.14.2 a) 101) 推荐的**最长搅拌篮（含延伸杆，如适用）** |
| 未规定篮长时 | 用 **1 m 长**搅拌篮做倾倒试验 |
| 姿态 | 工具**竖直放置**，搅拌篮**顶端抵在混凝土面上**，随后向三个不同方向倾倒 |
| NOTE | 典型搅拌篮长 600 mm，可用延伸杆最长约 400 mm |
| 附件 | 若按 §8.14.2 提供附件，须对**每个附件或附件组合**用**单独样机**重复试验 |

**不适用**（不做到落跌落试验）。

## 9 结构（§21 增补/不适用）

### 9.1 §21.18.1.1 增补——开关锁定装置位置
- 电源开关**锁定（lock-on）装置**（如有）须布置在**不松开任一手柄握持区（§19.4 要求的手柄）即可动作**的位置；
- 且设计须**不易被使用者手部意外锁在通位**；
- 符合性：目视检查；对握持区内的 lock-on 装置，用**直尺试验**——
  - 用 **25 mm 长直尺**下压 lock-on 装置；直尺**可朝向任意方向**，须同时**跨越 lock-on 装置表面及其相邻表面**。
- **欧版（EN 62841-2-10）附加要求**：搅拌机须满足二者之一——
  - 电源开关为**点动式（momentary）且无"通"位置锁定机构**；**或**
  - 电源中断后工具**不得在松手并重新操作开关之前自行再启动**。

### 9.2 §21.18.1.2 增补
搅拌机视为**存在意外启动风险**的工具。

### 9.3 §21.30、§21.35
**均不适用**。

## 11 噪声与振动（Annex I；欧版为规范性）

| 条款 | 要求 |
|------|------|
| §I.2.4 增补 | 噪声试验时搅拌机**垂直悬吊**，**不装搅拌篮** |
| §I.2.5 增补 | **空载**测试，所有转速设定装置调到**最高值** |
| §I.3.3.2 增补 | 传感器位置按 **Figure I.101**（X/Y/Z 三轴测量） |
| §I.3.5.3 增补 | **空载**、调速置最高、试验中工具**竖直握持**；在输出主轴（多主轴时选其一）上装**一个模拟试验搅拌篮**：钢杆 + 带不平衡量的铝轮（Figure I.102、I.103）；钢杆上端可改制以适配主轴 |
| §I.3.5.3 NOTE | 实测表明搅拌机实际搅拌材料时的振动发射值**接近甚至低于空载值**，因为主要振源是搅拌篮不平衡量——故此法给出**最坏情况值** |
| §I.3.6.2 增补 | 申报**最高发射手柄的振动总剂量值 a_h** 及不确定度 **K** |

**模拟试验搅拌篮（Figure I.102/I.103）关键尺寸**：钢杆 ∅16；铝轮（材料铝）∅100±0,2、内孔 ∅70±0,1、∅11,4±0,05、厚 6±0,05，不平衡量标注 **0,8**，倒角 2×0,3×45°，端面跳动 A 面 0,02/0,01。

| 条款 | 要求 |
|------|------|
| Annex K 前言 | 除本附录另有规定外，Part 2-10 正文全部条款适用；本附录写出的条款**取代**正文对应要求 |
| K.8.14.1.101 | **d)、f)、h) 项不适用**（电池机不要求"软缆远离""防液体溅入""掉入材料中立即拔插头"三条警告） |
| K.12.2.1 | **不适用**（不做 30 min 连续温升试验） |
| K.21.18.Z101 / L.21.18.Z101（**欧版增补**）隔离与禁用装置 | 带内置电池的工具须二者择一：**隔离装置**（防止维护/用户保养时机械伤害）或**禁用装置**（防止意外启动） |

**隔离装置要求（欧版）**：断开电池**全部极**与可维修区域；有与控制器每个位置对应的**明确断开状态指示**；**防意外重新接通**。NOTE 1 示例：可拆跨接件、可断开的内置电池、执行器与触点直接机械连接的机电开关；NOTE 2 开关的意外重接风险由 §21.18.1.2 覆盖。

**禁用装置实现方式（欧版）**：
- 自复位或非自复位 **lock-off 装置**，电动机接通前须**两个分离且不同性质**的动作（例如开关先按下再横向移动才闭合触点），**不得用一次握持或一次直线运动同时完成**；或
- 随工具提供的**可拆卸禁用件**，装上或取下时工具都**无法运行**。
- 符合性：目视检查 + 手动试验。

## 15 常见坑点

1. **"§12–30 直接适用"是错的**：§12.2.1 有 30 min 增补，§18/§19/§20/§21 多处替换或不适用，本部分也没有 §29/§30。
2. **手柄力臂是计算判据，不是目视判据**：要按 Figure 102 量 S 点和 x 点（80 mm 规则），再和**说明书声明的最大搅拌篮直径/宽度**比较——声明的篮越大，对力臂要求越严，两者必须成对提交。
3. **§19.101 的 40 mm 不只量主轴出口**：还须覆盖**沿搅拌篮向下 100 mm** 的范围。
4. **倾倒试验要装最长篮**：用推荐的最长篮（含延伸杆）做 3 次倾倒；没声明长度就用 1 m 篮——漏装篮直接按裸机做试验是无效试验。
5. **§20.5 不适用**：搅拌机不做到落跌落。
6. **夹头钥匙金属卡夹不得装在软缆上**：允许钥匙"轻易脱出"以外的存夹方式，但软缆上的金属夹明确禁止。
7. **lock-on 装置要能用 25 mm 直尺压住测试**：直尺须同时跨越装置表面和相邻表面，且可取任意方向——只测一个方向会被判试验不充分。
8. **欧版多做防再启动（PL b）和隔离/禁用装置**：CE 与 IEC 报告范围不同，电池机型尤其要分清。
9. **振动试验是空载 + 模拟不平衡篮**：不要按"实际搅拌"来测；标准已说明空载即最坏情况。
