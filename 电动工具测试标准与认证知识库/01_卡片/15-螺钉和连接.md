## 1 · 通用要求

### 1.1 机械应力

**依据**：IEC 60745-1 §27.1 / IEC 62841-1 §27.1 / IEC 60335-1 §28.1

- 可能影响符合性的紧固件和电气连接
- 必须能承受正常使用中的**机械应力**
- 检验：目视 + 手动试验

### 1.2 材质要求

**依据**：IEC 60745-1 §27.1 / IEC 62841-1 §27.1 / IEC 60335-1 §28.1

| 要求 | 说明 |
|------|------|
| 金属螺钉 | 不得为软金属或易蠕变金属（如锌、铝） |
| 绝缘螺钉 | 标称直径 ≥ **3 mm** |
| 绝缘螺钉 | **不得用于电气连接** |
| 传递电气压力螺钉 | 必须旋入**金属** |
| 绝缘螺钉替换风险 | 如金属螺钉替换会破坏附加/加强绝缘，则不得使用绝缘螺钉 |

---

## 2 · 拧紧试验

### 2.1 试验次数

**依据**：IEC 60745-1 §27.1 / IEC 62841-1 §27.1 / IEC 60335-1 §28.1

| 螺纹类型 | 拧紧次数 |
|----------|---------|
| 绝缘材料螺纹 | **10 次**（完全旋出再旋入） |
| 金属螺纹/螺母 | **5 次** |

### 2.2 扭矩值

**依据**：IEC 60745-1 Table 9 / IEC 62841-1 Table 11 / IEC 60335-1 Table 13

| 螺钉标称直径（mm） | 扭矩（Nm） |
|---------------------|-----------|
| ≤ 2.8 | 0.2 |
| > 2.8 ~ 3.0 | 0.25 |
| > 3.0 ~ 3.2 | 0.3 |
| > 3.2 ~ 3.6 | 0.4 |
| > 3.6 ~ 4.1 | 0.5 |
| > 4.1 ~ 4.7 | 0.6 |
| > 4.7 ~ 5.3 | 0.8 |
| > 5.3 | 1.0 |

### 2.3 扭矩施加列选择

| 螺钉类型 | 适用列 |
|----------|--------|
| 无头金属螺钉（不突出） | I |
| 其他金属螺钉和螺母 | II |
| 绝缘螺钉（六角头/圆柱头带槽/十字槽，尺寸 >1.5 倍直径） | II |
| 其他绝缘螺钉 | III |

### 2.4 试验条件

- 使用合适的测试螺丝刀、扳手或钥匙
- 端子螺钉试验时，放入最大截面的软线（§25.2 规定）
- 每次松开螺母时移动导线
- 试验后不得出现影响继续使用的损坏

---

## 3 · 电气连接特殊要求

### 3.1 接地连接

**依据**：IEC 60745-1 §27.2 / IEC 62841-1 §27.2 / IEC 60335-1 §28.2

- 接地连接螺钉必须有**锁定措施**防止松动
- 弹簧垫圈可提供满意锁定
- 密封剂（加热后软化）仅适用于不受扭转的螺钉连接
- 铆接电气连接：如日常使用中受扭转，必须防松动（非圆柄或适当缺口）

### 3.2 电气间隙和爬电距离

**依据**：IEC 60745-1 §27.3 / IEC 62841-1 §27.3 / IEC 60335-1 §28.3

- 内部接线和电气连接的布置
- 必须保证电气间隙和爬电距离不低于 §28/§29 规定值
- 即使螺钉松动也不得降低至规定值以下

## 5 · 常见坑点

1. **绝缘螺钉直径必须≥3mm**：小于 3mm 不合格
2. **绝缘螺钉不得用于电气连接**：这是基本原则
3. **传递电气压力的螺钉必须旋入金属**：旋入塑料不合格
4. **拧紧次数区分螺纹材质**：绝缘 10 次 / 金属 5 次
5. **扭矩值按直径分档**：不能随便拧，必须用扭矩工具
6. **接地螺钉必须有锁定措施**：弹簧垫圈或密封剂（有限制）
7. **密封剂仅适用于不受扭转的连接**：受扭转的连接不能用密封剂
8. **铆接电气连接受扭转时必须防松动**：非圆柄或缺口
9. **试验后不得影响继续使用**：出现损坏不合格
10. **电气间隙在螺钉松动后仍须保证**：这是容易遗漏的点
