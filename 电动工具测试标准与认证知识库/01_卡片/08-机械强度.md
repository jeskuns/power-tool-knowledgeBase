# 08 — 机械强度（Mechanical Strength）

## 0 · 速查结论

| 项目 | 电动工具（60745/62841/GB 3883.1） | 家用电器（60335/GB 4706） |
|------|--------------------------------------|---------------------------|
| 弹簧冲击锤 | 刷盖 0.5 J，其余 1.0 J | 统一 0.5 J |
| 跌落试验 | 手持 1 m / 混凝土；可移式钢球 1.3 m | 无 |
| 刷盖扭矩 | 0.4–1.25 Nm（6 档） | 不适用 |
| 手柄绝缘（切割类工具） | 1 m 跌落 + 1250 V 耐压 | 不适用 |
| 稳定性试验 | 不适用 | 10°/15° 斜面 |

---

## 1 · 试验条件与方法

### 1.1 弹簧冲击锤试验（所有产品通用）

**依据**：IEC 60745-1 §20.2 / IEC 62841-1 §20.2 / IEC 60335-1 §21.1

- 设备：按 IEC 60068-2-75 的弹簧冲击锤（spring-operated impact hammer）
- 试样固定方式：刚性支撑
- 每个可能薄弱的外壳点打击 **3 次**
- 必要时也打击手柄、杠杆、旋钮、防护罩等

**冲击能量**：

| 标准 | 刷盖 | 其余外壳 |
|------|------|---------|
| 60745-1 / 62841-1 | **0.5 ± 0.05 J** | **1.0 ± 0.05 J** |
| 60335-1 | **0.5 J**（统一） | 0.5 J（统一） |

### 1.2 跌落试验（仅电动工具）

**依据**：IEC 60745-1 §20.3 / IEC 62841-1 §20.3

**手持工具（20.3.1）**：
- 高度：**1 m**，混凝土表面
- 次数：3 次
- 放置方式：3 次分别以最不利的冲击点朝下（最低点距地面 1 m）
- 可分离附件不安装
- 如配有附加附件（8.14.2），需另取样品带附件重复

**可移式工具（20.3.2）**：
- 钢球直径：**(50 ± 2) mm**
- 钢球质量：**(0.55 ± 0.03) kg**
- 落差：**(1.3 ± 0.1) m**
- 方式：上方可冲击的部件——自由落体；否则——摆锤方式
- 防护罩脱落但可重新装回并正常功能 → 合格
- 变形但可恢复原状 → 合格
- 工具或传动系统损坏（防护罩除外）导致无法正常使用 → 不合格

### 1.3 刷盖机械强度（仅电动工具）

**依据**：IEC 60745-1 §20.4 / IEC 62841-1 §20.4

- 方法：拆换电刷 **10 次**，用测试螺丝刀拧紧刷盖
- 螺丝刀 blade 宽度尽量大，不超过盖槽长度；若螺纹直径更小则不超过螺纹直径
- 扭矩不得冲击式施加

| 螺丝刀 blade 宽度（mm） | 扭矩（Nm） |
|--------------------------|-----------|
| ≤ 2.8 | 0.4 |
| > 2.8 ~ 3.0 | 0.5 |
| > 3.0 ~ 4.1 | 0.6 |
| > 4.1 ~ 4.7 | 0.9 |
| > 4.7 ~ 5.3 | 1.0 |
| > 5.3 | 1.25 |

**判定**：刷握无损伤、螺纹无损坏、盖无裂纹

### 1.4 手柄绝缘强度（仅可能切割电线的工具）

**依据**：IEC 60745-1 §20.5 / UL 60745-1 §20.5

- 另取样品，每个手柄和握持面各承受 **1 次** 1 m 跌落至混凝土
- 跌落后可握持面接触锡箔，与工具输出轴之间施加 **1250 V a.c.** 耐压测试（按 §15）

### 1.5 稳定性试验（仅家用电器）

**依据**：IEC 60335-1 §20.1

- 不接电源，放在 **10°** 斜面上（最不利方向）
- 带门器具：门开或关，取最不利
- 需灌注液体：空或最不利水量
- 不应翻倒
- 带加热元件的器具：倾斜增至 **15°**；若翻倒，在翻倒状态下做 §11 温升测试

---

## 2 · 判定标准

### 2.1 冲击/跌落试验后

- 外壳损坏、小凹痕：**不降低**爬电距离和电气间隙至 §28.1 以下 → 可接受
- 小碎片：**不影响**防触电或防潮保护 → 可接受
- 装饰盖有内盖支撑：装饰盖碎裂但内盖通过试验 → 可接受
- 肉眼不可见裂纹、纤维增强模压件表面裂纹 → 忽略
- **机械安全功能不得受损**
- 试验后需通过 **耐压试验**（§15 / §16.3）

### 2.2 刷盖试验后

- 刷握无损伤，不影响继续使用
- 螺纹无损坏
- 盖无裂纹

### 2.3 稳定性试验后（家电）

- 不翻倒 → 合格
- 翻倒 → 在翻倒位置做温升试验，温度升高不得超过 §11 / Table 9 限值

**62841-1 vs 60745-1 关键变化**：
- 可移式工具跌落由 60745-1 的简单 1 m 跌落改为 62841-1 的 **钢球摆锤/落球 1.3 m**
- 62841-1 新增 K.20.3 电池工具跌落试验（1 m，3 次）
- 62841-1 Table 编号变化（Table 5→6, Table 4→5），数值不变

## 4 · 常见坑点

1. **家电只有 0.5 J**：60335-1 弹簧锤统一 0.5 J，不要误用工具的 1.0 J
2. **可移式 ≠ 手持**：可移式工具用钢球 1.3 m 落差，不是 1 m 自由跌落
3. **刷盖扭矩要匹配螺丝刀宽度**：不是随便拿一把螺丝刀拧，blade 宽度必须对应盖槽
4. **装饰盖碎裂不算不合格**：只要有内盖且内盖通过，装饰盖碎裂可忽略
5. **肉眼不可见裂纹忽略**：但功能性裂纹（降低爬电/电气间隙）不合格
6. **手柄绝缘试验后必须做耐压**：1250 V a.c.，7. 62841-1 的 Table 编号与 60745-1 不同，引用时注意区分
