## 做了哪些整理与清洗

1. **统一结构**：去掉两种原始机器头（页数/字符数/提取时间、OCR 免责头），改成一致的标题 + 引用块元信息 + `---` + 正文。
2. **标准号识别**：复用 `kb_index.parse_name`，从文件名解析标准号、年份、名称，用作文件名与标题；解析不出的退回原文件名。
3. **去噪**：删下载站水印行、纯页码行、重复页眉页脚（跨页出现 ≥60% 的短行）、目录点线与页码、`ICS/K 64/数码防伪` 等页边噪声。
4. **断行合并**：中文行尾无句末标点且下行不是标题时并回一行，修复 PDF 抽取与 OCR 把一句话拆成多行的情况。
5. **OCR 错字**：`—-`→`—`、`Safety--Part`→`Safety-Part`、`Ed 2. 0`→`Ed 2.0`、`日期.发布`→`日期 发布`、`∕`→`/`、压缩连续空格。
6. **章节可读化**：`1 范围`、`4.2 温升` 这类独立编号行转成 `##` 标题；目录页不转，避免误伤。
7. **页标记归一**：两类原文的分页符统一为 HTML 注释，渲染时不可见、回原件时可定位。
8. **去重**：清洗后正文去空白算 md5，内容相同的副本只留一份，并在头部注明合并了几份。

## 版本核查口径（必读）

- **离线部分（每份自动执行）**：把标准号与 `00_索引/现行标准清单.md`（50 条已人工联网核实的安规/EMC 现行标准）比对，
  再查 `_脚本/kb_std_latest.py` 的 `REPLACED`（已被代替）与 `SUPERSEDE_SOON`（即将被代替），给出版本状态。
- **联网部分（人工维护）**：本脚本**不发网络请求**；逐条联网核查的结论、来源链接与复核日期写在
  [核查记录.md](核查记录.md)。清单未覆盖的条目标「未纳入核查范围」，**不代表现行有效**。
- 状态只作检索辅助，**判定请用 PDF 原件或 `卡片/` 速查卡**；OCR 正文与 `MD?` 文字层的数值一律不可直接引用。
